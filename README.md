# 休息提醒 · Break Bell

这是一个 Manifest V3 浏览器扩展，浏览器打开时持续计时，电脑锁屏/睡眠时暂停；支持多个可编辑工作时段、工作间隔、休息时长，以及可单独开关的声音、Windows 系统通知和浏览器提醒弹窗。铃声包含强提醒、雨声、风声、白噪音、钢琴、萨克斯及氛围音乐，默认循环播放 5 分钟，时长可调整；在提醒弹窗点击“知道了”会立即停止声音，但不会改变计时状态。扩展主界面可暂停/继续整个提醒功能；无论当前在工作、休息还是时段外，暂停期间都不会累计时间或发送提醒。

## 安装

1. 打开 Chrome 或 Edge 的扩展管理页。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展程序”，选中本目录。
4. 点击扩展图标进入设置，调整工作间隔、休息时长和多个工作时间段。

设置会保存在浏览器本地。时间段之外自动视为休息；进入/离开每个工作段、工作间隔结束、休息结束都会提醒。
